# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Musicx takes the security and privacy of its users seriously. If you discover a vulnerability or security risk:

1. **Do not create a public issue.**
2. Send an email to the repository owner or open a private security advisory on GitHub.
3. Provide details about the potential vulnerability and steps to reproduce.

We will review your submission and respond promptly with a remediation plan.
